# Suggestions simples sur la fiche produit

Une seule section « Vous pourriez aussi aimer », quatre produits au maximum, sans ajout automatique au panier.

## Gestion dans l’admin
Sur un accessoire publié, utilisez les tags existants du produit :
- `protection-etb` : protection de coffret ETB ; priorité sur une fiche ETB.
- `sleeves` : pochettes de protection de cartes ; ETB, display, autres scellés ou carte à l’unité.
- `top-loaders` : protections rigides de cartes ; mêmes familles.

Renseignez le format, les dimensions et les limites de compatibilité dans la description réelle du produit. Un tag ne constitue pas une garantie de compatibilité universelle. Ne taguez pas un accessoire incompatible avec les formats vendus.

Deux accessoires au plus, puis les produits similaires disponibles remplissent les places restantes. Un produit ne peut pas apparaître deux fois. Les variantes affichées pour les accessoires doivent être actives, à prix positif et en stock. Les accessoires d’un autre jeu, les démonstrations et les précommandes sont exclus.
Les exemples publics n’inventent ni protections, ni packs, ni remise. S’il n’existe pas d’accessoire pertinent, seuls les produits similaires disponibles peuvent apparaître. En rupture, la section d’alternatives existante est prioritaire.
