Une carte code est une carte glissée dans les produits du JCC Pokémon qui porte un code à usage unique pour le jeu en ligne officiel, Pokémon TCG Live. Elle ne se joue pas dans le jeu physique et n’a pas de rareté.

## Où la trouver

Les [boosters](/glossaire/booster) des versions internationales, dont la version française, contiennent en général une carte code chacun. D’autres produits, comme certains coffrets ou decks, peuvent en inclure pour débloquer des contenus spécifiques dans le jeu en ligne. Dans un [ETB](/glossaire/etb), chaque booster apporte la sienne.

Les produits japonais n’en contiennent pas : c’est l’une des différences décrites dans la fiche [version japonaise](/glossaire/version-japonaise).

## À quoi elle sert

Dans le jeu en ligne, le code se saisit ou se scanne grâce à son QR code pour débloquer l’équivalent numérique du produit, par exemple un booster virtuel. Chaque code ne peut être utilisé qu’une seule fois.

C’est un pont entre les deux façons de jouer : un joueur peut ouvrir ses boosters physiques pour sa collection, puis retrouver l’équivalent numérique pour s’entraîner en ligne.

## Ce qu’il faut savoir

- Une carte code n’a pas d’intérêt de collection : seuls les codes inutilisés intéressent les joueurs en ligne.
- Achetée seule, une carte code comporte un risque : impossible de savoir si le code a déjà été utilisé avant de l’essayer. Gardez-le en tête avant de payer pour des codes vendus séparément.
- Le jeu en ligne et ses conditions d’utilisation relèvent de l’éditeur ; les contenus débloqués peuvent évoluer.

Pour situer la carte code dans l’univers du [JCC](/glossaire/jcc), elle fait partie des éléments qui distinguent les produits internationaux des produits japonais, au même titre que le nombre de cartes par booster.
